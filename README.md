# Excel_Sales_Dashboard_Project
Created an interactive Sales Dashboard in Microsoft Excel to analyze revenue, profit, orders, units sold, and costs. Used PivotTables, PivotCharts, and slicers to visualize monthly trends, compare country and regional sales, analyze sales channels, and filter results by product category and quarter for easy analysis and better decision-making.

# 📊 Excel Sales Dashboard

## 📌 Project Overview
This project uses Microsoft Excel to analyze sales performance and profitability through an interactive dashboard. It helps users understand revenue, profit, orders, and sales trends using charts and filters.

## 🎯 Objectives
- Analyze revenue and profit.
- Compare country and regional performance.
- Identify sales trends.
- Present data in an easy-to-understand format.

## 🛠️ Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Formulas
- Slicers
- Data Visualization
